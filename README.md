
**GenieVoyage** is a travel planning iOS app that helps users organize trips, manage itineraries and store all travel documents in one place.

---

## Features

-  **Trip Planning** — Create and manage trips with day-by-day itineraries

-  **Daily Itinerary** — Organize events by day with time slots

-  **Interactive Map** — View all locations on a map with custom markers

-  **Drag & Drop** — Add and rearrange events intuitively

-  **Document Storage** — Save PDF tickets and booking confirmations locally

-  **Booking Links** — Store and open links to reservations directly in Safari

-  **Trip Templates** — Ready-made itineraries for popular destinations (Paris, Tokyo, Santorini, Swiss Alps and more)

-  **Search** — Quickly find trips and locations

-  **Privacy First** — All data stored locally on device using CoreData. No servers, no accounts, no tracking.

---

| Technology | Usage |
|-----------|-------|

| MapKit | Interactive maps |
| CoreLocation | User location |

GenieVoyage does not collect or transmit any personal data. All trip data, photos and documents are stored exclusively on the user's device.
